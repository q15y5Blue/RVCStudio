RVC Studio 0.3.0 — 离线全量版

安装
运行 RVCStudio-Setup-0.3.0-offline.exe 即可，全程不需要联网。
安装向导会在本地合并、校验并部署已内置的约 4.93 GB 变声引擎（展开约 7.5 GB），
预置两把自然普通话女声模型，安装或复用 VB-CABLE 虚拟麦克风，并安装中文界面。
无需另外下载、手动安装或打开 Applio / VB-CABLE，也无需再下载模型。
建议预留 25 GB 磁盘空间。
安装驱动时请允许 Windows 管理员授权，首次安装完成后按提示重启电脑。
组件校验失败不会报告安装成功；可重新运行安装包，已部署内容会复用。

内置女声模型（已预置，默认选中主模型）
主模型 ChineseFemale：标准 RVC v2 / 200 epochs，干净标准普通话自然女声，默认使用。
备选   ChineseFemale_HQ：Ov2 增强底座 / 350 epochs / 40k / RMVPE，同一把自然女声。
两把都是自然说话风格（非卡通 / 非明星 / 非唱歌），均通过 RVC v2 校验。
在「① 模型与声音」页点「使用内置主女声」或「使用内置备选女声(HQ)」即可一键切换、A/B 对比。
你仍然可以用「导入模型」使用自己有权使用的 .pth，配套 .index 可选。

开始使用
1. 安装、按需重启后打开 RVC Studio，软件会自动检测显卡和音频设备。
2. 主模型已默认选中；建议先选一段音频做文件转换试听，或录音 15 秒并转换。
3. 实时页面选择真实麦克风，变声输出选择 CABLE Input (VB-Audio Virtual Cable)。
   软件检测到普通版 VB-CABLE 时会优先选择这一输出。
4. 微信 / Discord / QQ 的麦克风选择 CABLE Output (VB-Audio Virtual Cable)。
   聊天软件的扬声器仍然选择你的耳机。
5. 点击“开始实时变声”。如需听见自己的变声，启用额外监听并选择耳机。
6. 点击“停止”释放音频设备。「② 变声参数」中带 ● 的参数运行中拖动即生效，带 ○ 的需停止后重新开始。

CABLE Input 是本软件写入声音的播放端，CABLE Output 才是聊天软件选择的录音端。
选择耳机作为主输出只能自己试听；想让对方听见，要输出到 CABLE Input。
不要用音箱监听，以免声音被麦克风重复收到。
如果没有 CABLE 设备，先重启；仍没有时在“环境与驱动”页面点击安装/检测虚拟麦克风。
微信版本若不能单独选择麦克风，可在 Windows 声音设置中手动选择默认输入，再重新发起通话。
软件不会替你改动系统默认音频设备。

运行条件
Windows 10/11 x64，实时变声需可用的 NVIDIA CUDA 显卡及已安装的显卡驱动。
RTX 3070 是原指南的目标配置。无需自行安装 Python 或 CUDA Toolkit。
内置引擎基于 Applio 3.6.5（官方包，含 Python、推理依赖、ContentVec、RMVPE、FCPE）。
引擎运行在后台，不会打开 Applio 网页。文件转换可以尝试 CPU，速度视设备而定。

推荐参数
音调 +8；共振峰 0；检索特征占比 0.50；清辅音保护 0.35；响度因子 0.45；响应阈值 -60 dB。
RMVPE；ContentVec；采样长度 160 ms；淡入淡出 60 ms；额外推理时长 250 ms。
输入/输出降噪、Autotune、自动音高、相位声码器、独占 WASAPI 默认关闭。
没有 .index 时实际关闭特征检索。更换 .pth 时自动清空旧索引，避免误配。
先确认声音自然，再把采样长度降到 140、120、100 ms；丢块、爆音时回到稳定值。
“算法延迟”与原版 RVC 同口径：采样长度 + 淡入淡出 + 10 ms (+ 输入降噪约 40 ms) + 声卡缓冲；
不包含聊天软件和网络延迟。“单块推理耗时”需持续小于采样长度，否则会卡顿。
备选 HQ 模型若在你的显卡上更自然可直接使用；两者参数预设相同。

输出声音偏小怎么办
1. 首选调“③ 实时变声”或“② 变声参数”页的“输出增益（倍）”：1.0 为原始，1.5≈+3.5dB，
   2.0≈+6dB，3.0≈+9.5dB；边试边调，过高会削顶爆音。运行中修改即时生效。
2. 多数“声音小”根源在麦克风输入：Windows 设置 → 系统 → 声音 → 输入，
   把麦克风音量调高；声音控制面板 → 录制 → 麦克风属性 → 级别，可加“麦克风增强”。
   实时页下方电平条很低就说明进来的声音本身小，先把输入调大。
3. 通话软件（微信/Discord）里把麦克风选成 CABLE Output，并把该输入音量调到最大；
   播放设备仍选你的耳机/音箱。
4. “响度因子（音量包络 / Volume Envelope）”不是音量旋钮：0 = 输出完全跟随麦克风的响度起伏，
   1 = 使用模型自身的响度（通常更响、更稳定）；觉得偏小可从 0.45 调到 1 试试。
5. 还可在 VB-CABLE 控制面板（开始菜单 VB-CABLE）把 Output 的增益调高。

「② 变声参数」与原版 RVC 实时 GUI 的对应关系
音调设置 = 音调（半音）　　　性别因子/声线粗细 = 共振峰 / 性别因子（-2～+2，正值更细）
Index Rate / 检索特征占比 = 检索特征占比　　响度因子 = 响度因子（即 Applio Volume Envelope）
采样长度 / 淡入淡出长度 / 额外推理时长 = 同名参数（界面单位为毫秒）
响应阈值 = 响应阈值（噪声门）　　输入降噪 / 输出降噪 = 同名开关　　独占 WASAPI 设备 = 同名开关
音高算法：rmvpe / fcpe / crepe-tiny / crepe（原版的 pm 在 Applio 引擎中不可用）。
原版的“使用模型/设备采样率”不需要：引擎固定以 48 kHz 收发音频并自动重采样。
“清辅音保护”是 RVC 推理参数 protect，原版实时 GUI 未开放；越小越保护，0.5 为关闭，仅在使用索引时起作用。
男声转女声：先用音调把音高拉到女声区间（+8～+12），声音仍显“粗”时把共振峰调到 +0.5～+1.5。

Beatrice v2 引擎与 A/B 对比
除 RVC 外，内置第二个变声引擎 Beatrice v2（官方 beatrice-trainer 2.0.0-rc.0 的开源推理代码，MIT 许可）。
Beatrice 为实时设计，网络更小；它与 RVC 共用同一个内置 Python 环境，无需另外安装。
没有 NVIDIA 显卡时 Beatrice 自动改用 CPU：实测双核服务器 CPU 上采样长度 160 ms、额外推理时长 500 ms 每块约 130 ms，
可以实时；额外推理时长 1000 ms 时需把采样长度加到 240 ms。“单块推理耗时”须持续小于采样长度。
模型：只能导入训练检查点 checkpoint_*.pt.gz（用 beatrice-trainer 训练后输出目录里的 checkpoint_latest.pt.gz）。
  只给官方 VST / VCClient 用的 paraphernalia_* 文件夹是闭源引擎专用格式，无法导入；beta 版训练器的模型结构不同，也无法加载。
  多说话人模型的“说话人编号”按训练数据文件夹的顺序从 0 开始。
参数：Beatrice 只使用音调、共振峰、采样长度、淡入淡出、额外推理时长、响应阈值、输入降噪、输出增益和独占 WASAPI。
  共振峰按 0.5 取整（Beatrice 只训练了 -2～+2 的 9 档）；检索、清辅音保护、响度因子、音高算法、Autotune 等仅对 RVC 生效。
  Beatrice 的共振峰是模型学出来的，效果随模型和嗓音不同：实测有的声音 -2→+2 移动约 3 个半音，有的几乎不变。
  Beatrice 的网络会向后看约 27.5 ms，因此算法延迟比 RVC 同参数多 30 ms；额外推理时长建议 500～1000 ms，上下文越长越稳。
A/B 对比：
1. 「① 模型与声音」页同时设置好 RVC 和 Beatrice 的模型。
2. 文件：点“两种引擎各转换一次（A/B）”，结果文件夹里会生成 -RVC.wav 和 -Beatrice.wav；
   实时页的“录音 15 秒，两种引擎各转换”会对同一段录音分别转换，并保留 -original.wav 原声。
3. 实时：开始实时变声时会把两边的模型都加载上，点“③ 实时变声”页的“A/B 切换引擎”可边说边切换，
   指标栏会显示当前引擎；切换瞬间可能有一次轻微爆音。只设置了一种模型时只加载那一种。

数据、维护与卸载
数据目录：%LOCALAPPDATA%\RVCStudio，可从“环境与驱动”页面打开。
内含内置与个人模型、录音、参数、引擎及日志。
Windows 设置中可以卸载 RVC Studio。卸载保留个人数据和可能被其他程序共用的 VB-CABLE。
完整清理前请备份需要保留的模型和录音；删除 VB-CABLE 会影响其他使用该驱动的软件。
遇到错误时，查看界面底部日志，或导出诊断报告。
